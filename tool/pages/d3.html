Interactive showcase of the native Dart/Flutter D3 ports: CIELCh/Lab gamut slicer and CSS color inspector, van Wijk & Nuij smooth pan-and-zoom flight, perceptual color interpolation showdown, 2D affine transform animator, a live 60fps heatmap with color-vision simulation across all 76 d3-scale-chromatic palettes, an interactive d3-path SVG/dart:ui builder, d3-shape curves, arcs, streamgraph stacks, symbols, and links drawn straight to Canvas, an interactive d3-format specifier playground with all 59 locales, a live d3-array histogram, quantile box-plot, ticks/nice, and 1D/2D blur explorer, and interactive d3-contour marching-squares topography and 2D kernel density plots.
