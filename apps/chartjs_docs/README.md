# chartjs_docs

The documentation site of `flutter_chartjs_port`. Each example on a page is a live `ChartView`.

Run `dart run melos run docs` to open the site in Chrome.

The code panels read `lib/examples/line_examples.dart` as an asset. The markers `// #docregion <name>` and
`// #enddocregion <name>` select the lines of a panel. Thus a panel shows the code that draws its chart.
