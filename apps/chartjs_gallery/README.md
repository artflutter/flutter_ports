# chartjs_gallery

Gallery and visual test bed for [`flutter_chartjs`](../../packages/flutter_chartjs).
It lists every Chart.js chart type and will show each one as its port lands,
modelled on the [Chart.js samples](https://www.chartjs.org/docs/latest/samples/).

```sh
melos run gallery        # Chrome
melos run gallery:macos  # macOS
melos run gallery:build  # web build (WebAssembly with a JavaScript fallback)
```

Not published (`publish_to: none`).
