# Host seams: chartjs-plugin-zoom on the Chart.js port

This file lists each place where chartjs-plugin-zoom uses its host: the `chart.js` library and the
DOM of the browser. For each use, it gives the state of `flutter_chartjs_port` and the next step.
[Zoom ADR 0003](adr/0003-host-connection.md) gives the rules. [ADR 0009](../../../docs/adr/0009-add-on-ports.md)
gives the rule for all add-on ports.
[Chart.js ADR 0108](../../flutter_chartjs_port/doc/adr/0108-input-surface-and-exports-for-add-on-plugins.md)
is the host change for the gaps of the first list.

- Upstream: chartjs-plugin-zoom `v2.2.0+fb81d331`, the paths of `third_party/chartjs-plugin-zoom/`.
- Host: `flutter_chartjs_port` on 2026-11-10, commit `471cab7`, the merge point of zoom phase 3,
  the paths of `packages/flutter_chartjs_port/` and `packages/chartjs_test_utils/`. The code of the
  host is that of the host wave of Chart.js ADR 0108 (`0b09600`) with the follow-ups of the same day
  (the String switch guards of `core.scale.dart` and the doc of `canvas.dart`). The line numbers
  are those of that tree. The first list was written against commit `62b5477` (2026-10-30).
- This is the state at the end of zoom phase 4. Each row names the tests of the zoom port that pin
  it.
- A person writes this file. Each change that closes a seam updates its row in the same commit.

States:

- `connects`: the public libraries of the host give the use now. A test of the zoom port pins it
  when its module lands.
- `zoom-side`: the zoom port uses a Dart form. The host needs no change. An `adapt` row of
  [differences.md](differences.md) records each form that changes upstream lines.
- `gap`: the host needs a change, with a Chart.js ADR (Zoom ADR 0003 item 2).
- `examine`: the state is not known. A test must show it.

Chart.js ADR 0108 (accepted 2026-11-10) closes the gaps of the input path (H2 to H8), of the JS
runtime (H13), of the plugin object (H16) and of the spec harness (H23). The specs pin them with
synthetic events, and the port-only tests `test/port/handlers_test.dart` and
`test/port/gestures_test.dart` with the pointer and key events of Flutter on a `ChartView`. H8
still waits for its device check on Android and iOS (Chart.js ADR 0108 Open 1): evidence, not a
host change. The typed options slot (H18) and the theme extension (H19) wait for their own
Chart.js ADRs, in zoom phase 5 (Zoom ADR 0003 item 11). H18 also covers the inline plugins of a
typed config: `ChartConfig.plugins` takes only plugin Maps. H25 and H26 are new: the data-only
opt-in and the key order of the scales.
