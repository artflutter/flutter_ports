# @kurkle/color port differences

This file lists the hunks of ported code that do not translate the upstream lines. Each hunk
carries the line comment `// DIVERGES(kurkle): <ID>, <reason>`. `check:headers` pairs each marker
with a row of this file. A port-only file is not a row.

The ID starts with its category: `adapt`, `platform`, `theme`, `js-semantics`, `harness` or
`not-followed`, as in the [Chart.js port](../../flutter_chartjs_port/doc/differences.md). The
column "Upstream file@version:lines" names the pin at which the porter last checked the row. Each
bump checks every row.

The port uses no JS runtime. Dart `null` stands for JS `undefined` in each input and result.
`lib/src/numbers.dart` has the plain Dart forms of the JavaScript number operations that the
library relies on: `x | 0` (`toInt32`), the number of an input value (`toNumber`), the test
`if (x)` of a number (`isNonZero`) and the text of a number in a CSS string (`numberText`). They
give the upstream results for the values of the upstream tests and of the Chart.js port.
