# chartjs-chart-sankey port differences

This file lists the hunks of ported code that do not translate the upstream lines. Each hunk
carries the line comment `// DIVERGES(sankey): <ID>, <reason>`
([Sankey ADR 0002](adr/0002-file-naming-and-layout.md) item 11). A port-only file is not a row. A
skip reason `'diverges: <ID>'` names a row.

The ID starts with its category: `adapt`, `platform`, `theme`, `js-semantics`, `harness` or
`not-followed`, as in the [Chart.js port](../../flutter_chartjs_port/doc/differences.md). The
column "Upstream file@version:lines" names the pin at which the porter last checked the row. Each
bump checks every row.

A Dart form that translates the upstream lines is no row: a record for an object literal that only
one function reads, the facades of the options, `getMeta()` for `this._cachedMeta`, and the class
values `jsClass` of the two components
([Sankey ADR 0003](adr/0003-host-connection.md)).
