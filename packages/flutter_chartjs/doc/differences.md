# Chart.js port differences

This file lists the hunks of ported code that do not translate the upstream lines
([porting-flow.md](porting-flow.md) §4). Each hunk carries the line comment
`// DIVERGES(chartjs): <ID>, <reason>`. `check:headers` pairs each marker with a row of this file.
A port-only file is not a row. A hunk of a port-only file that gives a difference of a row carries
the marker of that row. An example is `jsGet` in `lib/src/js/js_object.dart`.

The ID starts with its category: `adapt`, `platform`, `theme`, `js-semantics`, `harness` or
`not-followed`. A skip reason `'diverges: <ID>'` names a row.
