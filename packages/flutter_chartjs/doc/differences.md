# Chart.js port differences

This file lists the hunks of ported code that do not translate the upstream lines
([porting-flow.md](porting-flow.md) §4). Each hunk carries the line comment
`// DIVERGES(chartjs): <ID>, <reason>`. `check:headers` pairs each marker with a row of this file.
A port-only file is not a row. A hunk of a port-only file that gives a difference of a row carries
the marker of that row. An example is `jsGet` in `lib/src/js/js_object.dart`.

The ID starts with its category: `adapt`, `platform`, `theme`, `js-semantics`, `harness` or
`not-followed`. A skip reason `'diverges: <ID>'` names a row.

The column "Upstream file@version:lines" names the pin at which the porter last checked the row.
Each bump checks every row (the column "Re-check on bump"). It moves each Chart.js citation to the
new version, also when the file did not change, and it gives the lines at the new pin
([upstream-tracking.md](upstream-tracking.md) §4.9). Thus all Chart.js citations name one
version. The line citations in the column "Reason" are at the same pin. The commit pin
`v4.5.1+7169e651` (2026-10-20) moved all Chart.js citations from `v4.5.1`. Only the lines of
`helpers.dom.ts`, `element.arc.ts` and `index.d.ts` changed.
